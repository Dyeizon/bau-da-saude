# Baú da Saúde
### Aplicação Web para Armazenamento de Exames Médicos

**Resumo**

<p align="justify">
A digitalização de diversos documentos está em expansão em todos os campos, o que vem tornando a manipulação eficaz de informações médicas pessoais uma necessidade crucial. Exames impressos são acumulados a cada visita ao médico, e é frequentemente difícil manter um controle manual desses arquivos, tornando propícia a perda de informações importantes da nossa saúde. O projeto chamado Baú da Saúde surge nesse contexto com o objetivo de proporcionar um melhor armazenamento, manuseio e análise dos resultados dos exames médicos, sendo aceitas na aplicação as categorias de exame: imagem; sangue; fezes e urina. No desenvolvimento do aplicativo foram utilizadas tecnologias modernas, no backend utilizou-se Node.js e Express.js; para o frontend utilizou-se TypeScript, Next.js e Tailwind CSS; e o MongoDB para o banco de dados. Para a documentação da API a ferramenta Swagger foi utilizada. Toda a gestão do projeto, como a atribuição de tarefas e gestão de prazos, foi realizada através do MeisterTask. Como resultado deste projeto, identificou-se que a boa organização e colaboração da equipe levou o projeto a ser concluído de maneira eficaz, podendo tornar-se um produto em um futuro próximo. Conclui-se então que o Baú da Saúde será uma grande contribuição para a gestão da saúde de diversas pessoas, já que facilitará o registro e acesso às informações médicas pessoais.
</p>

**Palavras-chave:** digitalização, armazenamento, exames médicos, saúde, gestão.

**Conclusão**

<p align="justify">
O projeto Baú da Saúde representa um passo importante na gestão de informações médicas pessoais, usufruindo da tecnologia para oferecer uma solução eficaz e segura. Ao centralizar e organizar os resultados de várias categorias de exames, a aplicação, além de facilitar o acesso dos usuários às suas informações de saúde, também reduz o risco de perda de dados importantes, como pode ocorrer ao armazenar exames impressos. Com isso, pode-se concluir que esse projeto contribui para uma gestão de saúde mais fácil e eficiente.
</p>
