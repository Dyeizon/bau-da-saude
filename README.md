# Baú da Saúde
### Aplicação Web para Armazenamento de Exames Médicos

**Resumo**

<p align="justify">
Com o progresso da tecnologia e a crescente digitalização dos serviços de saúde, a gestão eficiente de informações médicas se tornou crucial. Pacientes frequentemente acumulam diversos exames ao longo do tempo, e a organização manual desses documentos pode ser desafiadora e propensa a falhas. Surgiu, então, o aplicativo "Baú da Saúde", com o intuito de oferecer uma solução sólida para armazenar, gerenciar e compartilhar resultados de exames médicos, com foco especial em exames de sangue. A metodologia utilizada no desenvolvimento do aplicativo inclui tecnologias modernas como Node.js e Express para o backend, React para o frontend, e MongoDB como banco de dados para a persistência dos dados. Uma abordagem ágil de desenvolvimento foi adotada, com iterações frequentes para assegurar a implementação eficaz dos requisitos. A documentação da API foi feita com o uso do Swagger, proporcionando uma interface completa e intuitiva para os usuários interagirem com os endpoints disponíveis. Este aplicativo busca simplificar o acesso às informações médicas e melhorar a comunicação entre pacientes e profissionais de saúde, automatizando processos e garantindo a confiabilidade dos dados. Dessa forma, o "Baú da Saúde" representa uma contribuição relevante para a saúde digital, facilitando uma gestão mais integrada e eficaz dos registros médicos, e promovendo melhores cuidados.
</p>
